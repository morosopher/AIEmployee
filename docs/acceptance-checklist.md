# M1 验收清单

每项必须附上日期、执行人、合成测试数据标识及命令/截图/审计事件链接。不得在记录中写入
Token、Cookie、完整邮件正文或个人资料；未通过或被环境阻塞的项必须明确标记，不能以推测替代证据。

## 功能与可信执行

- [ ] 审核 OAuth 请求 scope，证据证明只使用 Gmail 与 Calendar 的只读 scope。
- [ ] 以合成帐户分别触发定时与手动简报，保存任务、Outbox 与简报版本证据。
- [ ] 每项重要结论能打开对应 Gmail 线程或 Calendar 事件来源链接。
- [ ] 注入单来源失败，页面展示缺失来源、最后成功同步时间、错误类型和修复动作，简报为 partial。
- [ ] 让简报逾期超过十五分钟，确认首页红色告警与诊断任务；重复扫描不产生第二个诊断任务。
- [ ] 断开 SSE 后刷新页面，确认从 PostgreSQL 事件/快照恢复终态和步骤。
- [ ] 用 fake-write 依次验证批准、拒绝、过期与载荷哈希过期；工具只在有效批准后恰好执行一次。

## 隐私与保留

- [ ] 删除来源缓存、单个对话、撤销会话和全部数据，逐项检查追加审计记录和用户隔离。
- [ ] 检查配置的正文、元数据、历史保留截止日期，以及 Redis 临时键 TTL。
- [ ] 对 JSON 日志和错误追踪做脱敏扫描，确认不存在 Token、密钥或完整正文。
- [ ] 在隔离环境完成一次加密 PostgreSQL 备份与恢复演练，并校验哈希。

## 发布门禁

- [ ] 使用 200 封合成邮件和 20 个合成日程运行简报，记录五分钟内完成的时间。
- [ ] 启动连续 14 天 soak，按日保存“无重复生成、无静默漏生成、供应商错误可见”的结果。
- [ ] 记录 `just ci`、部署合约脚本、Compose/Podman 健康检查与故障恢复测试的完整输出摘要。
